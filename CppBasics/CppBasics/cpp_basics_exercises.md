# C++ 基礎課題セット

`C-study` リポジトリの土台として使う基礎編。各問題は単体の `.cpp` ファイルにして、
`basics/01_variables.cpp` のような連番ディレクトリで管理すると後で見返しやすい。

解答コードはここには書かない。自分で書いて、コンパイル・実行して確認すること。
詰まったら考え方のヒントだけ見る → それでも無理なら聞く、の順で。

---

## 01. 変数・型・入出力

整数 `score`、浮動小数点数 `accuracy`（0.0〜100.0）、文字列 `playerName` を
標準入力から受け取り、以下の形式で出力するプログラムを書け。

```
Player: Wataru
Score: 1500 (Accuracy: 87.50%)
```

**要件**
- `accuracy` は小数点以下2桁固定で表示する（`<iomanip>` の `std::fixed` / `std::setprecision` を使う）
- `std::cin >> playerName` だと半角スペース入りの名前が読めないことに注意。なぜそうなるか説明できるようにしておく

## 02. 制御構文 — ダメージ判定

整数 `hp`（現在HP）と整数 `damage`（受けるダメージ）を受け取り、以下のルールで結果を出力する。

- `hp - damage <= 0` なら `"KO"`
- 残りHPが元のHPの20%以下なら `"Danger"`
- それ以外は `"OK"`

**要件**
- `if / else if / else` を使う
- 0〜100の間で `hp` をループ入力させ、`-1` が入力されたら終了する仕組みを `while` で実装する

## 03. 関数 — ダメージ計算式

以下のシグネチャの関数を実装せよ。

```cpp
int calculateDamage(int attack, int defense, bool isCritical);
```

**仕様**
- 基本ダメージ = `attack - defense / 2`（整数演算の切り捨てに注意）
- ダメージが0未満になる場合は最低1
- クリティカル時は最終ダメージを1.5倍（`static_cast<int>` で切り捨て）

`main` 側でいくつかパターンを試して、想定通りか手計算と比較すること。

## 04. 配列 と `std::vector` の違い

(a) 生配列 `int scores[5]` に値を入れて合計と平均を出す関数を書く。

(b) 同じことを `std::vector<int>` で書き直す。

**考察として書いておくこと（コメントでよい）**
- 配列はサイズを後から変更できないが `vector` はできる理由
- 関数に渡すときに配列は要素数を一緒に渡す必要があるが、`vector` は `.size()` を持っているので不要、という違い

## 05. ポインタと参照（C++特有・重要）

C#にはポインタの概念が薄いので、ここはしっかり手で動かして体に入れる。

```cpp
void doubleValue(int* p);   // ポインタ版
void doubleValue(int& r);   // 参照版
```

両方実装し、`main` で同じ変数に対して呼び出して結果が同じになることを確認する。

**追加課題**
- `swap(int* a, int* b)` を実装し、2つの変数の値を入れ替える
- なぜ値渡し（`int a, int b`）では入れ替えができないのか、コメントで説明する
- `nullptr` を渡した場合にクラッシュする例を一度わざと書いて、デバッガかコメントで「なぜ落ちるか」を確認する

## 06. 構造体と簡単なクラス

ゲームのキャラクターステータスを表す型を作る。

```cpp
struct CharacterStats {
    std::string name;
    int hp;
    int attack;
    int defense;
};
```

これをクラスに書き直し、以下を満たすようにする。

- メンバ変数は `private`
- コンストラクタで初期化
- `void printStatus() const;` でステータス表示
- `void takeDamage(int amount);` で `hp` を減らす（0未満にはしない）
- `bool isAlive() const;` で生死判定

**狙い**: `struct` と `class` の違い（デフォルトアクセス指定子だけが本質的な違いであること）を体感する。

## 07. 総合問題 — 簡易バトルシミュレーター

01〜06で作った要素を組み合わせる。

`CharacterStats` を2体作り（例: Player / Enemy）、`calculateDamage` を使って
交互に攻撃させ、どちらかの `hp` が0になるまでループするシミュレーターを作れ。

**要件**
- 各ターンの攻撃結果（誰が誰にいくつダメージを与えたか、残りHP）をログ出力する
- クリティカル判定は `rand() % 100 < 10`（10%）程度の簡易乱数でよい（`<cstdlib>` / `srand(time(nullptr))`）
- 最後に勝者を出力する
