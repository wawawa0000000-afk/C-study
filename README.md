# Cpp-Algorithms

C++で実装したアルゴリズム・データ構造の学習用コード集です。
基本的なアルゴリズムの理解を深めるため、標準ライブラリに頼らず自前で実装することを意識しています。

## 内容

| カテゴリ | 内容例 |
|---|---|
| ソート | バブルソート、クイックソート、マージソートなど |
| 探索 | 二分探索、深さ優先探索（DFS）、幅優先探索（BFS） |
| データ構造 | 連結リスト、スタック、キュー、二分木 |
| 動的計画法 | フィボナッチ、ナップサック問題など |

> 上記は一例です。実際のフォルダ構成に合わせて書き換えてください。

## 動作環境

- C++17 以降
- コンパイラ: g++ / clang++ など

## ビルド方法

```bash
g++ -std=c++17 -o output main.cpp
./output
```
